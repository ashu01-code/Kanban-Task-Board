# Kanban Task Board

A Trello-style task management board built with React.js and Vite.

## Features

- 3-Column Board: To Do, In Progress, Done
- Add, Delete, Edit Tasks
- Move Tasks with Buttons or Drag & Drop
- Priority System: High (Red), Medium (Yellow), Low (Green)
- Global Search
- LocalStorage Persistence
- Responsive Design

## Tech Stack

- React.js 18
- Vite
- dnd-kit
- localStorage

## Installation

```bash
npm install
npm run dev
